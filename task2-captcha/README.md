# CAPTCHA на PHP

Одна страница с формой и картинка, которая генерируется отдельным скриптом.

Запуск:

```
php -S 127.0.0.1:8091 -t .
```

Открыть http://127.0.0.1:8091/ и ввести код с картинки.

Как устроено. Код из пяти символов лежит в сессии, после проверки удаляется, поэтому одна и та же
картинка дважды не проходит. Похожие символы (I, O, 0, 1) из алфавита убраны. Рисуется через GD,
шрифт DejaVu, размер 18-30, наклон случайный. Фон это noise.jpg, поверх точки и линии.

Файлы: index.php с формой и проверкой, captcha.php с генерацией PNG 240 на 80, style.css.
