# PHP, практикум

Учебные задания по дисциплине «Язык программирования PHP»: консольная программа, CAPTCHA на GD и книжный интернет-магазин на PDO/SQLite.

## Задание 1. «Глухая бабушка» (`task1-grandma/grandma.php`)

Консольный диалог:

- на любую фразу без «!» в конце бабушка отвечает `АСЬ?! ГОВОРИ ГРОМЧЕ, ВНУЧЕК!`;
- если крикнуть (строка заканчивается на `!`), отвечает `НЕТ, НИ РАЗУ С <случайный год 1930–1950> ГОДА!`;
- чтобы уйти, нужно три раза подряд ввести ровно `ПОКА!` (три отдельные строки);
- `ПОКА! ПОКА! ПОКА!` одной строкой не считается, бабушка притворяется, что не слышит;
- любая другая фраза сбрасывает счётчик прощаний.

```bash
php task1-grandma/grandma.php
```

## Задание 2. CAPTCHA (`task2-captcha/`)

- `index.php`, форма: картинка, поле ввода, проверка ответа, счётчик неудачных попыток;
- `captcha.php`, генерирует 5 символов (без похожих `I/O/0/1`), рисует их на шумовом фоне `noise.jpg`
  через GD и `imagettftext`: размер 18–30 пт, шаг 40 пт, случайный наклон, шумовые точки и линии;
- код хранится в `$_SESSION['captcha_code']`, одноразовый: после проверки удаляется;
- ответ сравнивается без учёта регистра, выводится сообщение «верно / неверно».

```bash
php -S 127.0.0.1:8091 -t task2-captcha
# открыть http://127.0.0.1:8091/
```

## Задание 3. Книжный интернет-магазин (`task3-books/`)

- `db.php`, PDO + SQLite (`data/shop.sqlite`), таблицы `books`, `orders`, `order_items`, первичное наполнение 12 книгами;
- `index.php`, каталог с фильтром по жанру и поиском по названию/автору, добавление в корзину;
- `book.php`, карточка книги;
- `cart.php`, корзина: изменение количества, удаление, оформление заказа с сохранением в БД (транзакция);
- стили, `style.css`, адаптивная сетка.

```bash
php -S 127.0.0.1:8092 -t task3-books
# открыть http://127.0.0.1:8092/
```

## Что показано по PHP

Работа с формами (`$_POST`), сессии (`session_start`, корзина и CAPTCHA), GD (`imagecreatetruecolor`,
`imagettftext`, `imagepng`), PDO с подготовленными запросами и транзакциями, SQLite, экранирование вывода
(`htmlspecialchars`), фильтрация e-mail (`filter_var`), редиректы после POST, простая шаблонизация.

## Требования

PHP 7.4+ (проверено на 7.2 и 8.x), расширения `gd`, `pdo_sqlite`, `mbstring`.
